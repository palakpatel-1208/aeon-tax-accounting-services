# Aeon Tax Services

Static website for Option 2. Open `index.html` in a browser, or upload this folder to any static host.

## Pages

- `index.html` — Home
- `services.html` — Services
- `about.html` — About Us
- `contact.html` — Contact Us

Styles are in `assets/css/style.css`. Shared behavior (menu and contact form) is in `assets/js/main.js`.
